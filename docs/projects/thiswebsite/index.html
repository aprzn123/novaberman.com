There's not a whole lot to say here. I really like using Zola to build HTML templates for my websites. I'm hosting it on GitHub Pages for now, just because it's quick and easy, but at some point I'll get a VPS back up and running and I'll host it on there instead. I do really value the fact that it's fully functional even with little-to-no JavaScript, though.

Colophon

This website was written with the Zola static site generator, which uses the Tera templating language. The source code can be found on GitHub. The headers are set in Lato by Łukasz Dziedzic, and the body copy in Roboto Slab by Christian Robertson. Both typefaces are sourced from Google Fonts. The color scheme is SLSO8 by Luis Miguel Maldonaldo.
